# Agenda de contatos | Interface e modelagem em Python

Projeto de agenda com modelagem de contatos, arquivo CSV e estrutura de interface gráfica em Tkinter.

**Formação e fundamentos** · Projeto de curso

[← Portfólio de Thiago Oliveira](https://github.com/thiagoramos20042/thiagoramos20042) · [Catálogo de projetos](https://github.com/thiagoramos20042/thiagoramos20042/blob/main/PROJETOS.md)

## Objetivo

Praticar organização de dados e construção de telas para uma agenda de fornecedores a partir de um enunciado de curso.

## O que você encontra

- Classe para representar contatos.
- Estrutura de telas de inclusão, remoção, busca e exportação.
- CSV e especificação do exercício disponíveis para consulta.

## Tecnologias

Python · Tkinter · CSV · Orientação a objetos

## Arquivos principais

| Arquivo | Conteúdo |
| --- | --- |
| [guiapp.py](guiapp.py) | Interface gráfica e navegação entre telas. |
| [contato.py](contato.py) | Modelo de contato. |
| [contatos.csv](contatos.csv) | Arquivo de contatos do exercício. |
| [Projeto (1).pdf](Projeto%20%281%29.pdf) | Especificação do projeto. |

## Como explorar

Para abrir a interface, com Python e Tkinter disponíveis:

```bash
python guiapp.py
```

Consulte as classes das telas para acompanhar a implementação de cada ação.

## Contexto do projeto

Projeto desenvolvido no contexto da formação Let’s Code. O enunciado descreve requisitos de uma agenda completa; a interface versionada apresenta a estrutura de navegação e não deve ser tomada como comprovação de todos os requisitos implementados.
